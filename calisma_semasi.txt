ZYRAENA - GERCEK CALISMA SEMASI (koddan cikarildi, 2026-10-21; API Process isaretleri 2026-10-22)
=====================================================================

Kisa ozet: Senin bildigin semadan en buyuk fark su: "API process -> Task -> Tool -> Done -> API process"
tek bir cagri degil, bir DONGU. Model her araci cagirdiginda arac PC'de calisir, sonucu modele geri
gider ve model YENIDEN cagrilir (en fazla 20 tur). Her turda sistem promptu + TUM sohbet gecmisi +
49 aracin tanimi bastan gonderilir. Konusma tarafi (STT ve TTS) tamamen yerel, ucretsiz.

Isaretler:
  [API Process]  = API kredisinden PARA HARCAYAN adim (OpenRouter veya Tavily)
  [yerel]        = PC'de calisir, ucretsiz

---------------------------------------------------------------------
6) PARA NEREYE GIDIYOR (credit_log.sqlite'tan olculen)
---------------------------------------------------------------------

 Sesli turlar: 16 kayit, toplam $0.153, tur basina ortalama ~$0.0096, ortalama 2.4 istek/tur.
 Ornek turlar (hepsi API Process A):
   istek 1: 6260 prompt token,  96 cevap token  (arac: list_directory)
   istek 2: 5043 prompt token,  28 cevap token  (arac: open_path)
   istek 3: 5084 prompt token,  12 cevap token  (son cevap)

 Yani maliyetin ~%95+'i GIRDI tokeni, cikti degil. O girdinin buyuk kismi her istekte tekrar
 gonderilen 49 arac tanimi (~5-6 bin token). Cevabin uzunlugu maliyeti neredeyse hic etkilemiyor.

 Yapi degisikligi icin en buyuk kaldiraclar (buyukten kucuge, hepsi API Process A'yi kucultur):
   1. Her istekte 49 aracin hepsini gondermemek: istege gore kucuk bir arac alt kumesi sec
      (yerel anahtar kelime / yerel kucuk model ile yonlendirme). Tek basina en buyuk kazanc.
   2. Sik komutlari modele hic gondermemek (Telegram'daki /iptal gibi): "muzigi durdur",
      "sesi ac", "ekran goruntusu" gibi kaliplar yerelde eslenip direkt arac calistirilabilir.
   3. Arac sonrasi "son cevap" istegi: basit araclarda (open_path, medya) sonucu sabit bir
      cumleyle dondurup 2. istegi atlamak.
   4. Gecmisi kirpmak / ozetlemek (simdi hic kisaltilmiyor; uzun Telegram sohbetlerinde buyur).
   5. Saglayici tarafi prompt cache: sistem promptu + arac tanimlari sabit oldugu surece
      onbellege alinabilir. Saat sistem promptunun sonunda; dakikada bir degistigi icin
      sabit kisim ondan once kalmali (simdi de oyle).
